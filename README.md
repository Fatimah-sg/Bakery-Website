A fully static bakery website built as a front‑end practice project using HTML, CSS, and simple layout techniques. The site showcases a modern bakery brand with a warm aesthetic, product listings, and clean UI sections inspired by real bakery websites.

Features:
- Responsive Header Section - Includes navigation, logo, search, and cart icon.
- Bakery Menu Highlight - Intro section with a call‑to‑action button.
- Sweets Menu - Organized categories for cookies, scones, and other baked goods.
- Product Grid (“Our Bread”) - Six bakery items with images, descriptions, and “Add to Cart” buttons.
- Subscription - Simple email input form encouraging users to subscribe.
- Footer Section - Contains quick links, help pages, contact details, and another subscription field.
- Clean, modern design with bakery‑themed colours and imagery.

Tech Stack: 
- HTML5 - Semantic structure
- CSS3 - Custom styling, layout, and typography
- Images - From the internet

This project was created to practice:
- Structuring multi‑section webpages
- Working with images and layout
- Designing product cards
- Improving front‑end styling skills
- Building a cohesive brand theme
